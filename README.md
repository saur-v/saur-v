## Projects

**ECG Signal Digitizer**
Built a deep learning pipeline that converts ECG paper records and PDFs into numerical time-series signals. Trained on PTB-XL rendered ECG images at clinical standards (25 mm/s, 10 mm/mV, 300 DPI). Achieved RMSE of 0.05 mV and correlation up to 0.97 — meaning the reconstructed waveform is nearly identical to the original signal. The system handles lead isolation, baseline normalization, and resampling to 100 Hz automatically.

**YouTube Transcript QA Bot**
AI-powered chatbot that answers questions about YouTube video content using a RAG pipeline. Built with LangChain, FAISS for vector retrieval, and LLaMA 3 on Groq for low-latency inference. Django REST backend handles video ingestion, transcript parsing, and query routing. React frontend lets users submit any YouTube link and get context-aware answers in real time.
